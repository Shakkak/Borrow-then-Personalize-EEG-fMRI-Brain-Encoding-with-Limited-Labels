# THINGS-EEG1 follow-up family

After P-1's verdict, three follow-up tests on the same 24 reserved people were declared, in a fixed order, before any
of them was run. Each is tested at α = 0.05/3, with Bonferroni over its own comparators inside, so the family's
error stays at 5%. Any further confirmation requires fresh participants.

1. **08h**: borrowing plus a correction on [shared-network latent, image features], against P-1's five comparators.
2. **08m** (P-2, `eeg1_h8_protocol.md`): does borrowing still win when the new person's whitening is estimated from
   only their k labelled trials?
3. **08n** (P-3, `eeg1_h4b_protocol.md`): the personal map against six comparators, including the generic map.

The third slot was first meant for a different test that had no design yet and was never run; it was given to the
personal map before the slot was used, which changes no executed test. Cost stated in advance: the per-comparator
critical t rises from about 2.50 to about 2.9 (23 df), so a borderline effect is likely to come out inconclusive.
